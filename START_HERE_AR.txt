مساعد الذكي AI — حزمة المشروع النهائية التجريبية
الإصدار: 0.5.0

محتويات الحزمة
1) web/
   - index.html: واجهة عربية RTL.
   - manifest.webmanifest + sw.js + icon.svg: أساس تثبيت الموقع كتطبيق PWA.
2) android/
   - مشروع Android Studio مبدئي يستخدم WebView ويعرض نفس الواجهة محلياً.
3) START_HERE_AR.txt
   - خطوات تشغيل الموقع وبناء APK.

المتاح فعلياً في هذه النسخة
- لوحة واجهة عربية للجوال.
- حفظ بيانات الواجهة محلياً في المتصفح/الجهاز (بحسب المتصفح وإعداداته).
- مسودات إعلانات وقوالب نصوص.
- إدارة روابط منتجات وإضافة وسوم UTM للمشاركة.
- بعض أدوات الواجهة تعمل محلياً ولا تحتاج حساباً خارجياً.

غير متاح أو غير مفعّل بعد
- لا يوجد APK مبني أو موقّع داخل هذه الحزمة.
- لا يوجد خادم خلفي أو قاعدة بيانات سحابية أو مزامنة بين الأجهزة.
- لا يوجد اتصال API حقيقي بمتاجر Amazon/Noon/Temu/AliExpress/SHEIN.
- لا يوجد توليد AI متصل بمفتاح API.
- لا يوجد نشر تلقائي أو جدولة فعلية لمنصات التواصل.
- لا يتم قياس النقرات/المبيعات بمجرد إضافة UTM؛ يلزم مصدر تحليلات أو واجهة المتجر.
- الحماية المحلية إن ظهرت في الواجهة ليست بديلاً عن تشفير وتسجيل دخول آمن على خادم.

تشغيل الموقع
- للتجربة السريعة: افتح web/index.html في متصفح حديث.
- لتثبيته كتطبيق PWA: ارفع مجلد web إلى استضافة HTTPS، ثم افتح الرابط في Chrome على Android واختر
  "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق" إذا ظهر الخيار.
- قد لا تعمل خصائص Service Worker عند فتح الملف مباشرة من file://؛ يلزم HTTPS أو localhost.

بناء تطبيق Android APK
1) ثبّت Android Studio على الكمبيوتر.
2) افتح مجلد android من Android Studio.
3) اسمح بمزامنة Gradle وتنزيل Android SDK المطلوبة.
4) من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) سيظهر APK في مسار app/build/outputs/apk/debug/ داخل المشروع بعد نجاح البناء.
هذه الخطوات تحتاج كمبيوتراً وAndroid SDK واتصال إنترنت. لم يتم اختبار بناء APK في بيئة هذه المحادثة.

قبل الاستخدام التجاري
- سجّل في برامج العمولة الرسمية واقرأ شروط كل برنامج.
- استخدم روابط العمولة المعتمدة الخاصة بحسابك فقط.
- احصل على موافقات وصلاحيات API الرسمية قبل جلب المنتجات أو النشر.
- أفصح بوضوح عن أن الرابط قد يكون رابطاً تسويقياً بالعمولة.
- لا تضع مفاتيح API السرية داخل HTML أو تطبيق الجوال؛ تحفظ في خادم آمن.

الخطوة اللازمة لتحويله إلى منتج متكامل
إنشاء خادم آمن + قاعدة بيانات + ربط API/AI + OAuth للمنصات + نظام تحليلات + اختبار أمني
ثم بناء APK موقّع وإعداده للتوزيع.
